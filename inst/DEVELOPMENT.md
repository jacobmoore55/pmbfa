# Implementation map

The package has four exported fitting functions and registered S3 methods.
All native wrappers in R/RcppExports.R are internal. RcppExports files are
generated by Rcpp::compileAttributes(); do not edit them by hand. No sourceCpp
call, runtime compiler, or source-file search is used after installation.

| Module | Responsibility |
|---|---|
| R/api.R | pmbfa and pmsbfa entry points |
| R/search.R | public searches and factor-grid/coordinate search |
| R/validation.R | inputs, factor bounds, labels and controls |
| R/models.R | constraint enumeration, canonicalization and nested bound |
| R/initialization.R | reproducible seed handling |
| R/selection.R | fixed shared initialization banks and adaptive stages |
| R/fit.R | grid orchestration, failure objects and criterion eligibility |
| R/parallel.R | installed-namespace socket workers |
| R/timing.R | original-call metadata and public/per-result wall-clock timing |
| R/methods.R | fitted-object and grid S3 methods |
| R/diagnostics.R | internal component means and score diagnostics |
| src/pmbfa_types.h | shared types and declarations |
| src/matrix.cpp | small Cholesky solves and low-rank precision operators |
| src/parameters.cpp | parsing, projection, serialization and parameter count |
| src/distributions.cpp | Bessel/GIG functions and family shape updates |
| src/expectation.cpp | density, responsibilities and conditional moments |
| src/location.cpp | location/shared skewness and warm-start PCG |
| src/scale.cpp | streamed sufficient statistics and scale updates |
| src/em.cpp | full accepted-cycle AECM state and stopping rules |
| src/initialization.cpp | candidate generation, screening and short refinement |
| src/api.cpp | thin registered Rcpp entry points |

The C++ modularization changes organization, not the mathematical update order.
Each fit still runs in a single compiled call; the hot loop does not call R.
Only optional initialization k-means calls stats::kmeans.

## Component-size protection

The legacy cN > 6 condition is strict. Every initial state used for fitting and
every proposed full cycle must have ng > min.component. A proposed violation is
rejected before parameters, likelihood, posterior or convergence are accepted.
The previous complete state is retained with status insufficient_component_size.
Diagnostics preserve the rejected effective sizes separately from accepted sizes.
Initialization screening uses the same strict rule. A zero-cycle evaluator can
return an unelectable raw likelihood for diagnostic use. All unconverged native
and R objects have score Inf; raw BIC/ICL remain available.

## Nearly singular scales

The fixed diagonal floors, Cholesky/positive-quadratic checks, stable precision
operators, full-cycle likelihood checks and explicit failure status are retained.
The package adds no automatic jitter or hidden covariance modification.
Positive definiteness alone does not cap a condition number when loadings become
large. Additional safeguards can be studied without lowering the bounds:
post-fit condition-number diagnostics, an explicit condition-based eligibility
rule, or a documented loading/covariance penalty. Each affects either selection
or the objective and should be specified and tested before becoming a default.
Penalized fitting also requires an explicitly chosen model-selection criterion.

The tests check extreme finite loadings, strict boundary counts, proposed final
collapse, matching failure snapshots, and exclusion of attractive raw criteria
from invalid fits. Independent numerical references check actual densities and
updates rather than merely repeating implementation formulas.

## Compiler compatibility

Rcpp automatically includes pmbfa_types.h when generating native wrappers.
The header locally suppresses unknown diagnostic-group names while including
external R/Rcpp headers under Clang. This accommodates R headers that mention
warning groups unavailable in the installed Apple Clang version. Diagnostics
are restored before compiling package code; no package-code warnings or
floating-point checks are disabled.

## Public call and runtime metadata

A scalar result contains call and elapsed (numeric wall-clock seconds). A grid
keeps whole-request metadata as list attributes, preserving one fit per entry.
Entries retain the original call and per-tuple or per-G search elapsed time.
Public factor searches invoke a private fitting adapter so the returned call
does not embed literal arrays or function closures from do.call.

Verbose summaries are emitted after constraint selection for each direct-fit
(G,q,r) tuple, or after the complete factor search for each G. The search
adapter suppresses intermediate tuple reports without changing fitting
controls. Parallel-grid summaries are emitted in the parent process after
workers return. Per-cycle native likelihood output has its separate
track_likelihood control.
The legacy quiet argument is normalized after control merging: explicit
quiet=FALSE enables summaries, and quiet=TRUE disables them. The demo has
no additional table or diagnostic printouts; tests check all console output.

See FUNCTIONS.md for the function-by-function reference. The executable demo
uses 200 normal PMBFA observations of 8 by 8 matrices, balanced groups, true
q=r=2 and covariance model CCC-CUC. Its only fitting call is search_pmbfa(x, G = 1:4, verbose = TRUE), using default adaptive
factor search, both constraint directions, automatic factor limits and default
initialization/stopping controls. The true factor counts describe generation
and do not restrict the fitted search.
